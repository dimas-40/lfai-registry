# 법인 설립(주식회사) 서식 범용 프롬프트 팩 v1

> **용도:** 유저가 **자기 AI(ChatGPT/Claude/DeepSeek 등)에 그대로 붙여넣어** 표준 서식을 생성하는 범용 프롬프트.
> **원칙:** 이 팩은 **표준 양식을 채우는 범용 템플릿**입니다. 특정 사안에 대한 법률 판단·자문을 하지 않습니다.
> 내용·결정·책임은 **본인**에게 있고, 생성된 서식은 본인이 검토 후 사용합니다. (법률 자문 아님)
> 표준서식 출처: 대법원 인터넷등기소 / startbiz.go.kr 공개 표준양식.

사용법: 아래 **① 내 정보**를 자기 값으로 채운 뒤, ②~⑤ 중 필요한 프롬프트와 함께 자기 AI에 붙여넣으세요.

---

## ① 내 정보 (먼저 채우기 — 이 블록을 각 프롬프트 앞에 붙임)
```
[회사정보]
- 상호(국문):
- 상호(영문, 선택):
- 본점 소재지(도로명 주소):
- 사업목적(한 줄씩):
  - 
- 1주 금액(원): 5000
- 발행예정주식총수:
- 설립 시 발행주식총수:
- 자본금(원):
- 결산기(예: 매년 12월 31일):
- 공고방법(예: 회사 인터넷 홈페이지 / 서울시 발행 ○○일보):
[발기인·주주] (여러 명이면 반복)
- 성명 / 주민등록번호 / 주소 / 인수주식수:
[임원]
- 대표이사 성명 / 주민등록번호 / 주소:
- 이사(사내) 성명·주소:
- 감사 성명·주소(자본금 10억 미만이면 생략 가능):
[설립일자]
- 발기인총회(창립총회) 일자:
```

## ② 정관 생성 프롬프트
```
너는 대한민국 주식회사 '표준정관' 양식을 채우는 작성 보조 도구다.
아래 규칙을 지켜라:
- 내가 제공한 [회사정보]만 사용해 표준정관 형식으로 작성한다.
- 법률 판단·자문·조언을 하지 않는다(종류주식·스톡옵션 등 특수조항은 내가 명시하지 않는 한 넣지 않는다).
- 상법상 정관 '절대적 기재사항'(목적, 상호, 발행예정주식총수, 1주 금액, 설립시 발행주식총수, 본점소재지, 공고방법, 발기인 성명·주민번호·주소)이 빠지면 "⚠️ 미기재: ___" 로 표시만 하고 임의로 지어내지 않는다.
- 출력은 제1조~부칙까지 완성된 정관 텍스트.

[여기에 ① 내 정보 블록 붙여넣기]
```

## ③ 발기인총회 의사록 프롬프트
```
너는 주식회사 설립 '발기인총회(창립총회) 의사록' 표준양식을 채우는 작성 보조 도구다.
- 내가 준 [회사정보]·[임원]·[설립일자]만 사용한다. 법률 판단은 하지 않는다.
- 표준 의사 순서(개회, 의장 선출, 정관 승인, 임원 선임, 본점·설립비용 결정, 폐회)로 구성한다.
- 빠진 값은 "⚠️ 미기재: ___"로만 표시.
- 출력은 완성된 의사록 텍스트(참석 발기인 서명란 포함).

[여기에 ① 내 정보 블록 붙여넣기]
```

## ④ 주주명부(주식인수) 프롬프트
```
너는 주식회사 '주주명부' 표준양식을 채우는 작성 보조 도구다.
- 내가 준 [발기인·주주] 목록만으로 표를 만든다(성명/주민등록번호/주소/인수주식수/인수금액/비율).
- 인수금액 = 인수주식수 × 1주 금액. 비율 = 인수주식수 / 설립시 발행주식총수.
- 합계가 자본금·발행주식총수와 안 맞으면 "⚠️ 불일치: ___"로 표시만.
- 법률 판단은 하지 않는다. 출력은 표 + 합계.

[여기에 ① 내 정보 블록 붙여넣기]
```

## ⑤ 임원 취임승낙서 프롬프트
```
너는 '취임승낙서' 표준양식을 채우는 작성 보조 도구다.
- [임원] 각각에 대해 "본인은 위 회사의 (직위)에 취임할 것을 승낙합니다" 형식의 승낙서를 1인 1장으로 만든다.
- 성명·주민등록번호·주소·직위·일자·서명란 포함. 법률 판단은 하지 않는다.
- 출력은 임원 수만큼의 취임승낙서 텍스트.

[여기에 ① 내 정보 블록 붙여넣기]
```

위 서식을 다 만든 뒤, 전산 입력을 위해 아래로 요약하면 내비게이터가 바로 읽습니다:
```
위에서 만든 내용을 profile/법인설립_프로필.schema.json 형식의 JSON 하나로 정리해줘.
값이 없는 필드는 null. 새로운 내용을 지어내지 말고 내가 준 값만.
```

> ⚠️ 이 팩은 **범용 양식 보조**입니다. 복잡한 지분구조·종류주식·정관 특례 등은 전문가(법무사·변호사) 검토가 필요할 수 있습니다. 본 도구는 법률 자문을 제공하지 않습니다.

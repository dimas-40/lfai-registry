How it works

서버는 길을 찾고,
폰이 실행합니다.

서버는 "어느 화면 어느 버튼"인지만 안내합니다. 주소·등기 내용 같은 개인정보는 폰을 떠나지 않고, 결제·발급은 본인이 폰에서 합니다.

계산식 · 월 절감 = 월 처리 건수 × 건당 직접 처리 시간 × 시간당 가치 − 월 처리 건수 × 1회 이용료. 입력값은 예시이며 업무마다 다릅니다. 등기 수수료(정부 납부분)는 별도입니다.

Parts

등기를 다루는
도구 묶음.

필요한 묶음만 펼쳐 보세요. 저장소에 있는 실제 도구 이름 그대로 적었습니다.

01

인터넷등기소(IROS) MCP

부동산·법인 열람
  • iros_connect일회성 무선ADB(페어링 코드=1회용 토큰)로 폰 연결 + 크롬 연동. 토큰은 세션 끝나면 폐기확인 필요
  • iros_status연결·크롬·열린 탭 확인 — 화면 안 바꿈일반
  • iros_open모바일 인터넷등기소 진입. 길찾기만 · 개인정보 없음일반
  • iros_search_realty부동산 주소 검색까지 — 주소는 폰 로컬 입력. 결제·발급 직전에서 정지확인 필요
  • iros_dump화면 구조만 덤프(태그·라벨) — 사이트 개편 시 셀렉터 재매핑. 개인정보 미포함일반
  • iros_disconnect세션 종료 — 연결·일회성 토큰 폐기일반
02

모바일 온디바이스 엔진

AutoJS6 · 폰 자체
  • AutoJS6 (접근성)폰 앱이 접근성으로 직접 실행 — PC·ADB 없이 폰 자체에서. 개인정보 로컬표준 엔진
  • 폰 = MCP 서버AutoJs6-Plugin-MCP-Server · 토큰 인증 Wi-Fi · 비전/스샷 없이 노드트리로 셀프힐링일반
  • 일회성 스크립트서버가 밀어주는 .js = 다운로드 → 실행 → 만료. 좌표 바뀌면 서버에서 재배포일반
  • 실측 근거m.iros 웹은 열람을 '앱 전용'으로 차단 → 앱을 접근성으로 조작하는 경로가 정답(실기기 검증)검증
03

안전장치 guard

넘지 말아야 할 버튼
  • check_label결제·납부·발급·서명·제출·삭제·인증서 라벨은 자동 클릭 차단 — 본인만안전장치
  • on_modal인증서 암호·카드번호·간편결제 모달 뜨면 확정 클릭 금지안전장치
  • is_app_gate'앱에서만 사용가능' 게이트 감지 — 웹경로 불가 시 앱경로로 전환 안내안전장치
04

등기 신청 준비

작성까지 · 제출은 사람
  • 부동산등기 신청신청서 기입 항목·첨부 서류 목록 정리 — 전자제출 화면에서 정지전문가 검토
  • 법인등기 신청등기 원인·당사자 확인 → 기입 항목 정리 → 첨부 체크리스트전문가 검토
  • 발급여부 확인발급한 등기사항증명서의 진위·발급 여부 조회일반
  • startbiz 연계법인설립 포털(startbiz) 등기 관련 절차 구조 매핑확인 필요
05

자료와 이력

  • STANDARD.md온디바이스(AutoJS6) vs 원격 ADB-MCP 지형 비교 · 기술 표준 결정 근거일반
  • SOLUTION-ARCHITECTURE.md"서버는 연산, 폰은 개인정보+실행" 전체 설계 · 백그라운드 실행 한계일반
  • 개인정보실제 등기 내용·주소는 저장소에 올리지 않음 — 공개 테스트 주소(공공건물)만 사용공개 범위

Boundary

넘지 않는 선.

등기 신청을 남 대신 하는 것은 법무사·변호사 업무입니다. 이 모듈은 본인 폰·본인 세션·본인 결제로만 돕고, 그 선 앞에서 멈춥니다.

Tool

도구가 한다

진입·길찾기, 주소/법인 검색, 화면 구조 확인, 발급여부 조회, 신청 서식 준비.

Person

사람이 한다

결제, 발급 확정, 공동·금융인증서 서명, 최종 제출(본인 인증).

Stop

코드가 멈춘다

결제·납부·발급·서명·제출·삭제 버튼은 guard가 차단합니다.

개인정보는 폰에만. 열람·발급은 공개등기라 인증서 없이 결제만으로 되지만, 결제와 발급 확정은 본인이 합니다. 등기 신청(소유권이전 등)은 전문가 검토를 거칩니다.

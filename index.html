③ 전산 자동입력

정부 전산 창을 순서대로 열고 내 서식 값을 자동 입력

→
본인

④ 결제·서명·제출

확정은 본인 손가락으로 — 도구는 여기서 멈춤

  • 왼쪽 시연 = 춤추듯 번갈아: 에이전트가 입력하고 → 멈춰 "확인?" → 본인이 반응
  • 에이전트가 지루한 입력을 끌고, 본인은 승인·서명·제출 턴만
  • 화면을 "뺏기는" 게 아니라 감독하는 오토파일럿 — 언제든 멈춤
  • 시작 전 방해금지(DND) 켜면 전화·알림에 안 끊깁니다
  • 내 정보(주소·주민번호 등)는 내 폰에만, 서버로 안 나감

STEP 2 · 사용법

에이전트 설치부터 내 폰에 한 줄로 깔고 시작

1

에이전트 설치

내 폰에 에이전트 베이스 termux-bridge를 curl 한 줄로. 여기서부터 시작 + 등기 모듈 추가.

2

서식 만들기

깔아둔 내 AI에 무료 프롬프트 넣어 정관·의사록 등 서식 완성 + 이용권 발급.

3

방해금지 켜기

실행 전 방해금지(DND)로 전화·알림 차단 → 30분 집중. 중간에 안 끊깁니다.

4

실행 → 본인

에이전트가 끌고(자동입력) 본인이 승인·서명·제출. 춤추듯 번갈아 진행.

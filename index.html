What it does

등기를 다루는
도구 묶음.

저장소에 있는 실제 도구 이름 그대로. 서버는 길을 찾고, 폰이 실행합니다.

01

인터넷등기소(IROS) MCP

열람 6종
  • iros_connect일회성 무선ADB(페어링 코드=1회용 토큰)로 폰 연결 · 세션 끝나면 토큰 폐기확인 필요
  • iros_open · iros_status모바일 등기소 진입 · 상태 확인 — 길찾기만, 개인정보 없음일반
  • iros_search_realty부동산 주소 검색까지 — 주소는 폰 로컬 입력, 결제·발급 직전 정지확인 필요
  • iros_dump화면 구조만 덤프 — 개편 시 셀렉터 재매핑, 개인정보 미포함일반
02

온디바이스 엔진 · 안전장치

AutoJS6 + guard
  • AutoJS6 (접근성)폰 앱이 접근성으로 직접 실행 — PC·ADB 없이 폰 자체, 개인정보 로컬표준 엔진
  • guard.check_label결제·납부·발급·서명·제출·삭제 라벨은 자동 클릭 차단 — 본인만안전장치
  • guard.is_app_gate'앱에서만 사용가능' 게이트 감지 → 앱경로로 전환 안내(실측 반영)안전장치
03

등기 신청 준비 · 자료

작성까지 · 제출은 사람
  • 부동산·법인등기 신청기입 항목·첨부 체크리스트 정리 — 전자제출 화면에서 정지전문가 검토
  • 발급여부 확인발급한 등기사항증명서의 진위·발급 여부 조회일반
  • FINDINGS · STANDARD2026-10-22 실기기 QA 기록 · 기술 표준 결정 근거일반

Boundary

넘지 않는 선.

본인 폰·본인 세션·본인 결제로만 돕습니다. 등기 신청을 남 대신 하는 건 법무사·변호사 업무 — 그 선 앞에서 멈춥니다.

Tool

도구가 한다

진입·길찾기, 주소/법인 검색, 발급여부 조회, 신청 서식 준비.

Person

사람이 한다

결제, 발급 확정, 인증서 서명, 최종 제출(본인 인증).

Stop

코드가 멈춘다

결제·납부·발급·서명·제출·삭제 버튼은 guard가 차단.

개인정보는 폰에만. 열람·발급은 공개등기라 인증서 없이 결제만으로 되지만, 결제·발급 확정은 본인이 합니다. 실기기 검증 기록 →

# 인터넷등기소(IROS) — 사이트 구조 정찰 (PC + 모바일)

> 대상: www.iros.go.kr (PC) · m.iros.go.kr (모바일)
> 목적: **부동산·법인 등기 열람/발급/신청 자동화** 구조 파악. ecourt(소송)·startbiz(법인설립)의 자매 노드 = **등기부등본·등기신청**.
> 운영: 대한민국 법원 법원행정처
> 정찰일 2026-10-22 · 비로그인 파싱 + AnySign 인증플러그인 실측(상세 필드/좌표는 인증 후 매핑 필요)

## 0. 한 줄
부동산·법인·동산채권 **등기사항증명서(등기부등본) 열람·발급**과 **등기 전자신청(e-Form)**을 온라인으로. 인코딩 EUC-KR, 인증서 플러그인(AnySign) 기반.

## 2. 기능 3구분 (자동화 난이도 핵심)
| 구분 | 설명 | 자동화 난이도 |
|---|---|---|
| **열람** | 화면으로 등기 내용 보기 (저렴) | ★ 쉬움 (조회+결제+캡처/PDF) |
| **발급** | 등기사항증명서 PDF 발급(인증) | ★★ (결제+PDF 저장) |

---

## 3. 인증 = PC 종속 관문 (★)
- **AnySign 인증서 플러그인** 사용 — `setPkiType4Sign`: **NPKI(공동인증서)·RPKI·GPKI·ALL** 인증서 목록.
- 이 플러그인이 **Windows/브라우저 보안모듈 종속**의 핵심(전자소송 공동인증서와 동형 벽).
- **돌파:** 모바일 인터넷등기소(m.iros) + 간편인증 확대 흐름 → 공동인증서 플러그인 우회 가능성. **열람/발급은 간편인증·모바일로 되는 범위 확인 필요.**

## 4. 모바일(m.iros) vs PC(www.iros)
| | 모바일 | PC |
|---|---|---|
| 열람 | 가능(중심) | 가능 |
| 발급(PDF 출력) | 제한적(출력은 PC 유리) | 가능 |
| 등기신청 e-Form | 제한 | 가능 |
| 인증 | 간편인증·모바일 인증서 | AnySign 플러그인 |
→ **모바일 1순위 타깃 = 열람/발급.** (신청은 PC 또는 반자동)

---

## 5. 자동화 설계 (ecourt/mobile 패턴 재사용)
- **경로 A(모바일웹+CDP):** m.iros 크롬 + `device-cdp` → 부동산 주소/법인명 입력 → 열람/발급 → PDF 저장. 1순위.
- **경로 B(PC+PyAutoGUI):** AnySign 필요한 신청은 `ecourt/pyauto` 방식(좌표 매핑)으로 PC에서.
- **사람 개입:** 인증서/간편인증 승인 · 전자결제 승인 · (신청 시) 전자서명.

## 7. ⚠️ 법적 경계
- **등기부등본 열람/발급 = 자유**(본인 아니어도 누구나 열람 가능한 공개 등기) → 자동 발급 보조는 문제 적음.

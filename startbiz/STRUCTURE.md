# StartBiz (온라인 법인설립시스템) — 사이트 구조 정찰

> 대상: https://www.startbiz.go.kr/index.do
> 목적: **법인설립 등기 + 사업자등록 자동화**를 위한 구조 파악 (ecourt=소송 자동화의 자매 — startbiz=법인설립등기).
> 운영: 중소벤처기업부 · 창업진흥원
> 정찰일: 2026-10-22 (상위 구조 = 비로그인 파싱 / 실제 신청 플로우·좌표는 인증 후 필요)

---

## 0. 한 줄
창업자가 법원 안 가고 **법인설립 등기·사업자등록을 온라인으로** 처리하는 정부 시스템. 전자서명 기반.

---

## 1. 메뉴 구조 (5대)
| 1단계 | 서브 |
|---|---|
| **스타트업 신청** | 사업자등록 · 펀딩 진행 · 기본정보 · **전자서명** · 스캔 업로드 |
| **스타트업 정보** | 소개 · 유의사항 · 용어 · 펀딩기관 · 회사 검색 |
| **스타트업 체험** | 체험 안내 · 체험 색인 |
| **협력센터** | 온라인 상담 · 공지사항 · FAQ · Q&A · 뉴스레터 · 전화 · 보도자료 |
| **스타트업 시스템** | 소개 · 설명 · 홍보영상 · 웹툰 |

## 2. 핵심 서비스
1. 법인설립 절차 지원
2. 사업자등록 처리
3. 설립 확인·관리
4. **전자서명 인증**
5. 1:1 온라인 상담

## 3. 로그인·인증
- 회원가입/로그인
- **전자서명(공동인증서) 기반 인증** — ecourt(전자소송)와 동일하게 인증서가 관문

---

## 4. 자동화 관점 (ecourt 패턴 적용)
| 단계 | 자동화 난이도 | 방식 후보 |
|---|---|---|
| 로그인·인증서 | ★★★ (인증서 보안모듈) | 반자동 — 사람이 인증, 이후 세션 유지 |
| 기본정보·폼 입력 | ★ 쉬움 | Browser Use / Skyvern(폼) 또는 PyAutoGUI(ecfs_pyauto 방식) |
| 전자서명 | ★★★ | 사람 개입 지점(보안) |
| 스캔 업로드 | ★★ | 파일 첨부 자동 |
- ★ **ecourt가 쓴 그대로 이식 가능:** `ecourt/pyauto/ecfs_pyauto.py` + `COORDINATES.md`(화면 좌표 매핑) 패턴 = startbiz 화면에 동일 적용.

## 6. ⚠️ 법적 경계 (ecourt와 동일 원칙)
- **법인설립 등기를 타인 대신 신청·대행 + 보수 = 법무사법 위반 리스크**(등기 대행은 법무사 영역).
- **안전형:** ① 본인이 직접 하도록 돕는 **셀프 자동화 툴/가이드**(대행 X) ② **법무사 제휴**(면허자 주체, 엔진만 공급).
- startbiz 자체는 "본인 셀프 신청" 시스템 → 셀프 자동화는 합법 경계 안.

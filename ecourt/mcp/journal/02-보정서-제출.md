# journal 02 — 보정서 제출 완주 (원본: 개발일지 073)

## 마감 계산
수신일 다음날 기산 N일째, 토·일·공휴일이면 다음 평일(민법 157·161). 예: 수신 9/18 + 21일 → 10/9 한글날 → 주말 → 10/12. 수신일은 로그인 후 "전체송달문서"에서만 확인. → `ecourt_deadline`

## 첨부 서류 판정
통과: 제목 [제출용]·전부증명서, 마지막 쪽 증명 문구와 관인, 1/N~N/N 전부. 탈락: "열람용" 워터마크, 일부증명서, "법적 효력 없음". 폰에서 넘어온 쪽 순서가 섞일 수 있음 — 눈으로 확인.

## 제출 경로
전체송달문서 → 명령 행 "관련서류 제출" → 서류 선택 → 1.문서작성(섹션마다 **"등록"** 필수, 첨부는 **"목록에 추가"** 필수) → 작성완료 → 2.최종확인 → 4.전자제출 화면에서 **에이전트 정지** → 사람이 문서제출·서명. 전자소송은 항상 "본문 서면 + 첨부" 세트. 접수 팝업은 참고용(캡처 보관).

## 역할
파일 회수·판정·병합·조회 = 에이전트 / 인증서 로그인·서명·제출 = 사람 / 폼 입력·첨부 = 에이전트(사람 동석).

## GUI 메모
- pyautogui fail-safe: 마우스가 (0,0) 모서리면 클릭 실패 → 중앙 이동 후.
- 파일 대화상자: 이름 칸 클릭 → 포커스(파란 테두리) 스크린샷 확인 → 전체경로 붙여넣기 → 확인 → 열기.
- 배너·스크롤로 레이아웃이 밀려 오클릭 2회 → 클릭 직전 스크린샷의 좌표만.
- 캡처: PowerShell CopyFromScreen 은 DPI 150%에서 잘림 → Windows python SetProcessDpiAwareness(2) + pyautogui.screenshot.

# journal 03 — 피고 답변서 수신, 사건 평가, MCP 확장 (원본: 개발일지 074)

## 무슨 일
- 피고(보험사) 답변서 송달. 정형문: 주위적(접촉 부위·인과 부인, "기왕 손상") + 예비적(원고 과실 20%). 증거 0, 대리인 없음, 사건명 오기.
- 사건이 본안으로 넘어감. 기일 통지는 아직.

## 도구 쪽 시행착오
| 문제 | 원인 | 해결 |
|---|---|---|
| 로그인 안 했는데 logged_in=true | 숨은 "로그아웃" 요소까지 셈 | 보이는 요소만 |
| 송달 목록 조회 타임아웃 | "로그인 안내" 모달이 버튼을 가림 | 상태 판정 수정 후 사람 로그인 |
| 상세 화면 링크 클릭 실패 | 투명 div 가 포인터 가로챔 | 글자 확인 후 DOM click (`safe_js_click`) |
| 문서 원문 추출 | 뷰어(streamdocs)가 blob 이미지, fetch 차단 | 이미지를 canvas 로 그려 PNG 저장 |
| 열람 시 수신일 확정 | 전자송달 효력 | `confirm_read` 없으면 열지 않음 |
| PDF 글자 추출 실패 | poppler 미설치 | Ghostscript 로 렌더 |
| 영상 접촉 순간 못 찾음 | Claude 는 프레임 샘플링만 가능 | 영상은 네이티브 영상 모델로 1차 → 시각만 받아 원본 프레임으로 확인 |
| 영상 모델 맞장구 | 맥락 먼저 주면 사용자 편 | 맥락 없는 블라인드 질문 (`blind_video_questions`) |

## 분석 쪽 시행착오 (에이전트가 반복하지 말 것)
- 증거 파일명의 대상(원고차/피고차)을 확인하지 않고 사진을 해석 → 피고차 사진을 원고차로 오인.
- 하지 않은 작업을 "해 두었다"고 보고 → 다음 턴에 정정. **실제 파일·커밋으로 확인한 것만 보고.**
- 견적서 원문을 안 보고 항목을 설명 → 틀림. 금액·항목은 원문으로.
- 대화형 AI 분석을 그대로 옮김 → 과장(법원 라벨, 서면에 없는 공격 의도, 확인 안 된 사실) 섞임. 원문 대조 필수.

## 사용자 결정 원칙
청구액·합의선·공개 범위·서면 제출은 사용자가 정한다. 에이전트는 계산·대조·초안·기록. 감정은 서면에 넣지 않는다(법정 말에서도 진실성 관문 통과한 사실만, 강도 조절).

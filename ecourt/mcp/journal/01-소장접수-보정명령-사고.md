# journal 01 — 소장 접수, 보정명령, 그리고 219개 파일 사고 (원본: 개발일지 072)

## 무슨 일
- 원고 본인이 소액 손해배상(자) 소장을 전자소송으로 접수. 다음 날 재판부 보정명령(피고 법인 등기사항증명서 제출, 21일).
- 비로그인 "나의사건검색"은 참고용 — 문서 원문·수신일은 정식 로그인 후에만 보인다.

## 사고
- PDF "다른 이름으로 저장" 대화상자에 파일명을 넣으려고 **스크린샷 확인 없이 좌표(700,700) 추측 클릭** → 실제 포커스는 파일탐색기 배경 → Ctrl+A, Ctrl+V 가 삭제성 동작 → Downloads 219개 휴지통 이동. PowerShell Shell.Application 으로 즉시 일괄 복구, 피해 없음.

## 거기서 나온 규칙 (이 MCP의 뼈대)
| 행위 성격 | 예 | 처리 |
|---|---|---|
| 내 문서 제출·저장 | 제출 버튼, 서류 파일 저장 | 사용자 동석 |
| 남의 공개정보 가져오기 | 등기부등본 열람·발급 | 무인 가능 |
| 단순 조회 | 진행·송달 조회 | 무인 가능 |
"위험하니 다 동석"이 아니라 **행위의 성격으로 리스크를 나눈 것**이 핵심.

## 기술 메모
- win32 직접 입력(SendInput 등)은 실패, pyautogui(Windows python)는 동작. 한글은 클립보드 + Ctrl+V.
- 전자소송과 인터넷등기소는 인증 세션이 따로 — 사이트마다 인증서 로그인 반복.
- 긴 법원 선택 드롭다운은 한글 IME 때문에 문자 점프가 안 됨.

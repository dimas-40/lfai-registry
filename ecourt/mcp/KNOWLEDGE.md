# 전자소송(소액 손해배상) 절차·교훈 가이드 — 일반 (사건 정보 없음)

> 사건 고유 정보는 `~/ecourt-private/cases/<사건>/` 에만 둔다. 이 파일은 공개 레포에 있어도 되는 일반 지식만.
> ⚠ "일반 법리" 표시는 이 레포 작업 중 원문 조문·판례를 직접 확인하지 못한 것 — 서면에 쓰기 전 확인.

## 1. 재판 구조 (누가 무엇을 입증하나)
| 단계 | 쟁점 | 입증 | 결과 |
|---|---|---|---|
| 1 책임 | 사고·피고 과실·접촉 | 원고 | 안 되면 전부 기각 |
| 2 손해·인과 | 어느 손상이 이 사고로 생겼고 얼마인가 | 원고 | 인정 안 된 항목만큼 기각 |
| 3 과실상계 | 원고 과실로 감액? | 피고 (일반 법리) | 인정 비율만큼 감액 |
- 파손 부위 다툼은 감액이 아니라 **2단계(원고 입증)**. 주위적 주장이 받아들여지면 0원, 예비적(과실 %)만이면 (1−%) 지급.
- 인정액 = 인정된 손해액 × (1 − 과실비율). 이자도 줄어든 원금 기준.
- 소송비용: 패소자 부담 원칙(민소 98), 일부 패소는 법원 재량(101) — 일반 법리. 본인소송 시 인건비·시간은 소송비용·손해에 불산입(일반 법리). 차량 물건손해 위자료는 보통 불인정(일반 법리).

## 2. 지연손해금 (`ecourt_interest`)
- 소장 청구취지 기준: 사고일~소장부본송달일 연 5%, 다음날~완납 연 12%(소촉법). 소촉법상 항쟁이 상당하면 **선고일까지 5%만** 인정되는 경우 있음(일반 법리).
- 220만원 기준 하루: 5% 약 301원 / 12% 약 723원. 전액 인용 3개월 ≈ 7.4만원, 6개월 ≈ 14만원(송달 10/1 가정).

## 3. 송달·열람 (⚠ 중요)
- 전자송달 문서를 **조회(열람)하면 그 시각이 수신일**로 기록된다. 미열람이면 등재 후 일정 기간 지나 송달 간주(일반 법리). 제출기한이 있는 문서는 열람일 기준으로 기한이 계산되므로 열기 전에 확인. → MCP는 `confirm_read=true` 일 때만 연다.
- **무인 조회·알림 불가**: 로그인에 인증서 암호가 필요하고 세션이 약 30분. 대신 법원이 송달 시 보내는 **이메일 알림**(발신 scourt.go.kr)을 감시하는 방식이 현실적.
- 화해권고결정·이행권고결정·조정갈음결정은 송달 후 **2주 이내 이의**하지 않으면 확정(일반 법리). 오면 즉시 대응. `ecourt_deadline` 으로 마감 계산.
- 소액사건은 첫 기일에 변론 종결을 지향, 조정으로 끝나는 경우가 많다(일반 법리). 법원 숙제 유형: 석명, 증거 제출 요구, 조정회부, 보정명령.

## 4. 도구 사용 규칙·교훈
- 서명·"문서제출"·결제·삭제 버튼은 코드가 차단(guard). 인증서 암호는 박씨만. 클릭·첨부·폼입력은 박씨 동석, **조회만 무인**.
- `logged_in` 은 "로그아웃" 글자가 **화면에 보일 때만** 참(숨은 요소 오탐 사고 2026-10-02).
- 투명 div 가 링크를 가로채면 일반 click 이 실패 → `safe_js_click`(요소에 직접 click, 글자 확인·금지 검사는 동일).
- 문서뷰어(pvo.scourt.go.kr streamdocs) 쪽 이미지는 canvas 로 그려 PNG 저장. PDF 글자 추출 도구(poppler)는 이 PC에 없음 → gs(Ghostscript)로 렌더/텍스트 추출.
- 영상은 PNG 접촉 시트(ffmpeg tile)로 훑되 **접촉 순간을 못 찾았으면 못 찾았다고 말한다**. 사진 파일명(갑 호증의 대상 차량)을 반드시 확인 — 갑6을 원고차로 오인한 사례.
- 외부 AI 분석문은 원문 대조 전에 믿지 않는다. 확인된 것/추측/법리(미확인)를 분리해서 말한다.

## 6. 영상 증거 분석 플러그 (2026-10-03)
- **Claude(앱·Code 모두)는 영상을 네이티브로 보지 못한다.** ffmpeg 로 프레임을 뽑아 정지 이미지로 본다 → 프레임 사이 찰나(접촉 순간)를 놓칠 수 있다. 실제로 [사건번호] 에서 1~4초 간격 시트로는 접촉 순간을 못 찾았다.
- **Gemini 는 영상(시간축·오디오)을 네이티브로 처리** → 영상 1차 분석은 Gemini, 그 결과(시각·장면 설명·핵심 프레임)를 Claude 로 가져와 법리·서면·증거번호에 반영, 실행·기록은 Claude Code.
- Claude 쪽 보완: 사건 시각이 특정되면 그 ±3초를 **원본 fps 전체**로 뽑는다(`ffmpeg -ss T-3 -t 6 -vf fps=원본`), 차량 부위는 crop 확대. 못 찾으면 "못 찾았다"고 보고.
- 확인 항목: 접촉 시각, 접촉 부위, 각 차량 번호판, 바퀴 방향, **영상 타임스탬프 vs 소장 기재 사고시각 정합성**, 영상이 원본인지(모니터 재촬영 여부).
- ⚠ 업로드 주의: 증거 영상을 YouTube 에 올려 Gemini 에 보이는 방식은 **제3자(행인·다른 차량·상대 운전자) 노출** 위험 — 비공개/일부공개라도 링크 유출 가능. Gemini 에 파일을 직접 주는 방식(앱 첨부 또는 API 파일 업로드)이 낫다. API 는 과금 → 사전 확인.
- **Gemini 결과도 믿지 않는다 (할루시네이션·편향 실제 경험, 박씨).** 운용 규칙:
  1. **블라인드 질문 (박씨 원조 기법):** 사건 맥락을 먼저 설명한 대화에 영상을 주면 모델이 맞장구친다 → 박씨는 영상을 YouTube 에 올려 "당사자가 아닌 제3자 영상"처럼 맥락 없이 분석시켰다(분석 직후 삭제). 같은 효과를 공개 업로드 없이 내려면 **새 대화 + 파일 직접 첨부 + 맥락 없는 질문**. 어느 차가 우리 차인지, 우리가 원하는 결론을 알려주지 않는다. "두 차량의 움직임을 시각과 함께 객관적으로 기술하라", "접촉이 있었다면 그 근거 프레임 시각을, 없다면 없다고"처럼 양쪽 가설을 다 열어 둔다.
  2. **시각 단위 주장만 받는다:** "접촉했다" 같은 결론 대신 "MM:SS.ss 에 무엇이 보인다"는 형태로 답하게 한다.
  3. **프레임으로 확인:** 그 시각 ±3초를 ffmpeg 원본 fps 로 뽑아 **Claude Code**(원본 파일을 로컬에 가진 쪽 — 앱 Claude 는 영상을 직접 처리 못 함)가 직접 보고, 최종 확인은 박씨 눈으로. 프레임에서 확인 안 되는 Gemini 진술은 쓰지 않는다.
  4. 같은 질문을 두 번 이상 새 대화로 돌려 답이 흔들리는지 본다.

## 7. 지인 실무자 자문 플러그 (2026-10-03)
- 상대 서면을 쓴 쪽(예: 보험사 손해사정)의 **실무 관행**은 같은 업계 지인이 가장 잘 안다 → 법리(AI)와 실무 감(지인)을 교차.
- 순서: 이해충돌 확인(상대 회사 소속이면 묻지 않음) → `expert_consult` 프롬프트로 사실만 담은 블라인드 질문 → 답을 사건 폴더에 기록 → 원문·법리와 대조 후 서면 반영.
- 지인 의견은 **방향 잡기용**. 법원 증거로 쓰려면 정식 손해사정서·의견서 등 별도.
- 자문 질문에 기록에 없는 사실을 넣지 않는다(예: 확인 안 된 "타이어가 터졌다", 이미 배제된 "다른 보험사 대납·구상").

## 8. 판례 채널 (2026-10-03)
- `law_search_prec` / `law_get_prec` / `law_verify_case_no`: 국가법령정보 Open API 원문을 직접 받는다(웹 조회 도구는 중간 요약을 거쳐 번호·문구가 바뀔 수 있음). 결과는 `~/.cache/ecourt/law` 캐시 → 같은 검색은 재호출 없음.
- 분업: 대화형 AI = 판례 후보 탐색·판단 / 에이전트 = 원문 확보·사건번호 검증·저장 / 서면 = 검증 통과한 것만 인용.
- 소스 지도: `references/legal-sources.md` (국내 MCP·API, 해외 판례, 수사학).
- **판례 수집 기준:** "비슷한 소액 사건 찾기"가 아니다(소액 판결은 이유 생략 가능·상고 제한 → 공개 판례 희귀, 일반 법리). **쟁점별로 대법원·고법이 법리(판단 기준 문장)를 명확히 적은 판결**을 찾는다. 가져올 것 = 판단 기준·증명책임·인과관계 요건 / 가져오지 않을 것 = 그 사건의 과실 숫자·사실관계·손해액.
- 서면에는 쟁점당 법리 문장 1~2개만. 나머지 판례는 스크랩북에서 상대 다음 수·판사 질문 대비용.
- 교통사고 과실비율은 판례보다 손해보험협회 「자동차사고 과실비율 인정기준」 도표가 실무 기준점 → 해당 유형은 별도로 확보(API 없음, PDF 수동).

# 사건 평가 프레임 — 변호사식 종합 평가 (일반, 사건 정보 없음)

> 실제 사건 평가서는 `~/ecourt-private/cases/<사건>/` 에 이 틀대로 쓴다. 이 파일은 공개해도 되는 일반 지식.
> 학문·역사 출처는 일반 지식 수준이며 원문 대조는 하지 않았다.

## A. 여섯 렌즈 (평가서 목차)
1. **사건이론** — 판사가 믿을 한 문장. 우리 쪽 vs 상대 쪽 각각 한 문장으로.
2. **입장 vs 이익** (하버드 협상학) — 당사자별 겉 입장과 실제 이익. 겹치는 이익 = 조정 공간.
3. **BATNA·기대값** — 판결 기대값 = Σ(결과 확률 × 금액) − 남은 시간·비용. 합의 최저선은 이 근처. 확률은 당사자가 넣는다(도구가 정하지 않음).
4. **결정나무** (소송 위험 분석) — 쟁점별 확률을 곱해 각 증거가 기대값을 얼마나 올리는지 본다 → 증거 수집 우선순위.
5. **판사 심리** — 한국 소액 단독판사: 다건·신속, 간결한 서면·객관 증거·합리적 당사자 선호, 조정 권고 경향(일반론). 감정 서면은 손해.
6. **우리 편향 점검** — 우리 정보도 틀릴 수 있다는 전제. 오인·과장 사례를 적어 둔다.

## B. 빌려 오는 학문 → 실무 도구
| 학문 | 도구 |
|---|---|
| 수사학(아리스토텔레스 로고스·에토스·파토스) | 서면: 로고스·에토스 중심, 파토스 절제 |
| 로마 수사학 쟁점이론(사실→성격→정당성) | 상대 주장 분류(부인 → 성격 다툼 → 감액) |
| 중세 스콜라 토론 | 준비서면 배열: 상대 주장 → 반론 → 증거 |
| 서사학·문학 | 사건이론 문장, 시간순 사실관계 |
| 인지심리·행동경제학 | 앵커링(첫 숫자를 먼저), 판사 피로 고려한 분량 |
| 증거학(위그모어 차트) | 주장–증거 연결 지도, 빈칸 = 수집 대상 |
| 법언어학 | 상대 진술의 표현·일관성 분석 |
| 시각 설득 | 사진 대조판, 위치도, 타임라인 |
| 연극·성우 | 조정·법정 답변 태도: 짧고 차분하게 (배심 없는 한국에선 비중 작음) |
| 법경제학·의사결정분석 | 기대값, 결정나무 (`ecourt_expected_value`) |

## C. 역사적 원형
- 아테네 로고그라포스: 당사자 대신 변론문을 써 준 사람 — 나홀로소송 + AI 작성의 원형.
- 로마 키케로·퀸틸리아누스: 구상·배열·표현·기억·발표 5단계.
- 중세 교회법·대학: 서면주의, 증거 등급 → 대륙법·한국 서면 중심 절차.
- 청 송사(訟師)·조선 소지 대필: 관청 상대 문장력과 예법.
- 문화권 차이: 미국(배심)=연극·심리 비중 큼 / 한국(직업 판사)=문장·논리·증거 정리·시각 자료.

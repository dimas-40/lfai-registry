# 범위(Range)·스코프(Scope) — 세계 전자소송 지형 (2026-10-03, 앱 Claude 리서치 / Claude Code 미검증 표시)

> 분류 기준: "개인이 혼자서, 처음부터 끝까지, 온라인으로" 소액·민사 소송을 할 수 있는가. 세계 순위 공식 통계는 없음 → "1등"이 아니라 "최상위권".
> 각 항목은 아래 출처 기반 요약이며 Claude Code 가 원문 확인하지 않았다(⚠). 사업 자료에 쓰기 전 원문 재확인.

## 1군 — 개인 혼자 끝까지 가능, 오래 운영
| 나라 | 특징 |
|---|---|
| 한국 | 2011년부터 민사 전 영역 전자소송, 전국 단일 시스템, 본인소송 가능, 민사 전체 |
| 영국 | 금전청구 온라인 접수(Money Claim Online 계열) 오래됨 |
| 캐나다 BC주 | 소액은 온라인 분쟁해결 기관 Civil Resolution Tribunal(법원 아닌 재판소) |
| 싱가포르 | 소액심판소 온라인 접수 |
| 중국 | 인터넷 법원(항저우·베이징·광저우), 위챗 모바일 법원 — 인터넷 관련 분쟁 위주 |
| 에스토니아 | 전자정부 기반 전자소송 조기 정착 |

## 2군 — 있지만 반쪽이거나 막 시작
| 나라 | 이유 |
|---|---|
| 미국 | 주마다 다름, 연방은 변호사 중심, 일부 주 ODR 시범 |
| 일본 | 2026-05-21 민사재판 전면 전자화 시행. 변호사 의무, 본인소송은 선택 |
| 독일 | 독촉절차 온라인, 소송 전반은 변호사 중심 |
| 브라질 | 전자 절차 있으나 지역 편차 |
| 호주 | 주별 시스템 |

## 스코프 판단 (이 MCP·방법론이 겨냥하는 범위)
- **Range(지금):** 한국 전자소송 + 본인소송 + 소액 민사(교통 물적손해 1호 사건). 마스터맵 J01.
- **Scope(확장):** ① 한국 민사 8개 유형(AGENTS.md §8) ② 같은 구조의 1군 국가(절차·인증 방식은 나라마다 재설계) ③ 일본 — 2026-05 전자화 직후·본인소송 비중 낮음 → 한국의 15년 앞선 경험이 참고 사례가 될 수 있는 인접 시장(buckleychang 국제 트랙 후보, 사업성은 미검토).
- **Out of scope:** 변호사 대리가 필수인 절차, 법률사무 대행(변호사법 경계 — 본인이 자기 사건을 하도록 돕는 도구·교재까지).

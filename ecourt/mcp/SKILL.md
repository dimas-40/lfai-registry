# 전자소송 서류 제출 체크리스트

> 원본 기록: `~/ecourt-private/073-bojeong-submission-2026-09-28.md` (1회 완주, [사건번호] 보정서).
> 이 스킬 = 에이전트용 실행 순서. 도구 코드 = `~/buckleychang.com/tools/ecourt/` (조회 도구부터, 제출 준비 도구는 2회차에 동석 시험).

## 🔴 절대 규칙 (코드에도 동일하게 박혀 있음)

1. **서명·"문서제출"·결제 버튼은 절대 누르지 않는다.** 그 직전 화면에서 멈추고 박씨에게 넘긴다.
2. **인증서 암호는 박씨만.** 인증서 창까지만 띄운다.
3. **클릭·파일 첨부·폼 입력 = 박씨 동석 필수.** 조회(송달·진행 확인)만 무인 가능. 동석 확인 안 되면 멈추고 "PC 앞에 와야 진행 가능" 보고.
4. **사건 자료는 `~/ecourt-private/` 에만.** buckleychang.com 등 Pages 가 켜진 레포에 절대 커밋 금지 (2026-09-28 소장·등본이 buckleychang.com 으로 공개 서빙된 사고).
5. **파일 열기/저장 대화상자에서 Ctrl+A 금지.** 파일이름 칸 클릭 → 포커스(파란 테두리) 스크린샷 확인 → 전체경로 붙여넣기 → 경로 스크린샷 확인 → 열기. (2026-09-18 Downloads 219개 휴지통 사고)
6. **좌표 추측 금지.** 버튼은 글자/DOM 으로 찾는다. 좌표 클릭이 불가피하면 클릭 직전 스크린샷의 좌표만 쓴다 (배너·스크롤로 레이아웃이 밀림 — 09-28 오클릭 2회).

## 0. 준비

- [ ] 사건 폴더 `~/ecourt-private/cases/<사건>/STATUS.md` 읽기 — 마지막 상태·다음 할 일
- [ ] 첨부할 원본 확보 → 판정 (아래 §2) → `C:\Temp\ecourt\` 에 PDF 로 (Downloads 쓰지 않음)
- [ ] 텔레그램으로 첨부 PDF 박씨 크로스체크 (`~/dtslib-papyrus/telegram/.secrets.env` → `TG_PARKSY_BRIDGE_BOT`, chat id 는 `.secrets.env` 의 TG_CHAT_ID)
- [ ] 마우스가 화면 모서리(0,0)면 pyautogui fail-safe → 중앙으로 이동

## 1. 송달일·마감 확인 (조회, 무인 가능)

- 나의전자소송 → 나의문서함 → **전체송달문서** → 조회 → 해당 문서 행의 **수신일자**
- 마감 = 수신일 다음날 기산 N일째. 토·일·공휴일이면 다음 평일 (민법 157·161조)
  - 예: 수신 09.18 + 21일 → 10.09(한글날) → **10.12(월)**
- "나의사건검색"(비로그인)으로는 수신일 안 보임

## 2. 첨부 서류 판정 (법인 등기부 예)

| 통과 | 탈락 |
|---|---|
| 제목에 **[제출용]**, **전부증명서** | "열람용" 워터마크, **일부**증명서, "법적인 효력이 없습니다" |
| 마지막 쪽 "틀림없음을 증명합니다" + 등기정보중앙관리소 인 | 인·증명문구 없음 |
| 1/N ~ N/N 전부, 순서대로 | 누락·순서 섞임 (파일명 순서 ≠ 쪽 순서일 수 있음 — 눈으로 확인) |
| 상호·본점·대표자가 소장과 일치 | 불일치 |

- 법원이 보낸 **보정명령 등본은 첨부하지 않는다.**

## 3. 제출 준비 (동석 필수)

1. 박씨 인증서 로그인 (상단 "로그인" 링크 → 아이디 자동 → 로그인 → 인증서 창 → **박씨 암호**)
2. 전체송달문서 → 해당 명령 행 **관련서류 "제출"** → 제출 가능한 서류(예: 보정서) 클릭 → 사건확인 "확인"
3. **1.문서작성** — 섹션마다 **"등록"** 눌러야 저장 ("등록되었습니다" → 확인)
   - 명령 목록: 해당 명령 기본 선택 확인
   - 본문(보정 사유 등, 2000자): 클립보드 + Ctrl+V. 템플릿:
     > 위 사건에 관하여 원고는 YYYY. M. D.자 보정명령에 따라 ○○○를 첨부하여 제출합니다.
     > 첨부서류 1. ○○○ 1통
   - 서류명의인: 원고 본인 자동
   - 첨부: 서류명 드롭다운 기본 항목 우선(법인등기사항증명서·주민등록등본·소가계산서) → 파일찾기(§규칙5) → **"목록에 추가"** (필수) → 등록
4. **작성완료** → 2.최종문서확인 뷰어에서 본문·첨부 확인 → "모든 문서의 내용에 이상이 없음" 체크 → 확인완료
   - "작성문서 및 파일 삭제" 버튼이 바로 옆 — 누르지 말 것
5. **4.전자제출** 화면 = 여기서 멈춤. 제출서류 목록(본문 PDF + 첨부) 스크린샷 → 박씨에게 보고
   - 접수증명이 필요하면 **서명 전** "접수증명신청서 생성" (박씨 판단)
6. **박씨: 문서제출 → 인증서 서명**

## 4. 제출 후

- [ ] 접수증 팝업 캡처 — Windows python `SetProcessDpiAwareness(2)` + `pyautogui.screenshot()` (PowerShell CopyFromScreen 은 DPI 150%에서 잘림). 팝업은 "참고용, 법적 효력 없음" → 출력 불필요
- [ ] 본문 PDF: 뷰어 "파일저장" → `D:\UserFolders\Downloads` 에 바로 저장됨 → 사건 폴더로 복사
- [ ] 사건 폴더에 번호 매겨 보관 (NN_내용_날짜) → `STATUS.md` append → `~/ecourt-private` 에 커밋 (remote 없음)
- [ ] 텔레그램으로 접수증 캡처 전송
- [ ] 법적 증빙 필요 시: 나의전자소송 → 제증명발급 → 접수증명

## 박씨가 물을 수 있는 것

- "PDF 가 왜 두 개냐" → ① 본문(보정서 등) = 우리 답변서, 입력 문장으로 시스템 자동생성 ② 첨부 = 증빙 원본. 전자소송은 항상 세트
- "접수증 출력해야 되냐" → 아니오. 팝업은 참고용. 캡처 보관, 필요 시 제증명발급

## 1. 흐름 (시간순)
1. **10-02 밤** 박씨: [상대방 보험사] 답변서 송달 통보 받음 → "전자소송 MCP 띄워 확인". ecourt_status 가 `logged_in:true` 오탐(숨은 '로그아웃' 글자) → 수정(보이는 요소만).
2. PC 화면 검정(부재) → 귀가 후 박씨 인증서 로그인(암호는 본인).
3. **10-03 00:04** 전체송달문서에 `답변서부본(26.10.02.자)` 미확인 → 열람(이 순간 수신일 기록). 투명 div 가 링크 클릭을 가로챔 → DOM click 으로 우회. 문서뷰어(streamdocs) 쪽 이미지를 canvas 로 4쪽 추출. 박씨가 받은 PDF 는 텔레그램 전송.
4. 답변서 해석: 주위적(바퀴만 접촉·기왕손상·증거부족) + 예비적(불법주차 20%), 정형문, 증거 0, 대리인 없음. 사건명 "구상금" 오기.
5. 앱 Claude 분석 대조: "구상금=법원 라벨", "AUDATEX 정면 공격", "도로교통법 선제방어" → 원문에 없음. 사건명은 법원 화면상 손해배상(자).
6. 증거 20개 텔레그램 재전송. 사진·영상 직접 확인 → **갑6(피고차)을 원고차로 오인했다가 정정**. 영상: 접촉 순간·바퀴 방향 확인 못 함(프레임 한계).
7. DB손보 스티커 → 박씨: 자차 없음, DB는 출동만 → 대위 문제 없음.
8. 과실·이자·소송비용 계산, 재판 3단 구조(책임→손해·인과→과실상계) 정리. 박씨 결정: **청구 220만원 유지, 타이어 쟁점화 안 함**. (내가 "초안 만들어 둠"이라 했다가 실제 미작성 → 정정 후 v1 작성)
9. 심리 분석(운전자·보험사 가설) → 변호사식 6렌즈 평가 → 학문 차용(수사학·스콜라·위그모어·협상학) → 휘포크리시스(전달=연기, hypocrisy 동어원) → **진실성 관문 + 강도 다이얼** → 변증법 vs 수사학, 무트코트.
10. 공개 정책: 박씨 "주민번호만 빼고 공개" → 아이디만 환경변수로 분리. 전략·약점 문서는 판결 후 공개 권고, 제3자 정보 가림.
11. 영상: Claude 프레임 한계 → Gemini 1차 분석 분업. 박씨 원조 기법: 맥락 제거(제3자 영상처럼) 블라인드 분석. Gemini도 할루시네이션 → 시각 단위 주장만 받고 프레임으로 확인.
12. 투트랙 구조 확인: 붙여넣은 분석 = 앱 Claude.

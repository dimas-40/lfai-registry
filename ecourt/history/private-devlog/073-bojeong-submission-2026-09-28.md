## 3. 제출 경로 (교재용 — 이대로 따라 하면 됨)

1. 나의전자소송 → 나의문서함 → **전체송달문서** → 조회
2. 보정명령등본 행에서 발송/수신일자 확인 → 오른쪽 **관련서류 "제출"** → "제출 가능한 서류: 보정서" 클릭
3. 사건확인 (법원·사건번호 자동 입력) → 확인
4. **1.문서작성** — 섹션마다 "등록" 버튼을 눌러야 저장됨 ("등록되었습니다" 팝업 → 확인)
   - 보정명령 목록: 보정명령등본(2026.09.17) 기본 선택됨
   - 보정 사유 (2000자 이내):
     > 위 사건에 관하여 원고는 2026. 9. 17.자 보정명령에 따라 피고 [상대방 보험사] 주식회사의 법인 등기사항전부증명서(현재 유효사항, 제출용, 2026. 9. 21. 발행)를 첨부하여 제출합니다.
     > 첨부서류 1. 법인 등기사항전부증명서([상대방 보험사] 주식회사) 1통
   - 서류명의인: 원고 [원고] (자동)
   - 첨부서류: 서류명 드롭다운에 **"법인등기사항증명서" 기본 항목 있음** → 파일찾기 → **"목록에 추가"** (안 누르면 첨부 안 됨) → 등록
   - 안내: "첨부서류로 제출한 문서는 증거로 사용될 수 없으며" — 등본은 당사자 특정용이라 무관
5. **작성완료** → 2.최종문서확인: 뷰어에서 보정서·첨부 미리보기 → "모든 문서의 내용에 이상이 없음" 체크 → 확인완료
6. 4.전자제출 화면: 제출서류 = ① 소송문서 보정서(시스템 자동생성 PDF, 38.4KB) ② 첨부서류 법인등기사항증명서(2.05MB)
   - 접수증명신청서가 필요하면 **서명 전에** "접수증명신청서 생성"
7. **문서제출 → 인증서 서명 (본인)** → 접수증 확인 팝업 (참고용, 법적 효력 없음 → 출력 불필요, 캡처 보관)

### 왜 PDF 가 두 개인가 (박씨 질문)

- ① **보정서** = 보정명령에 대한 **우리 쪽 답변서**. Claude 가 문장을 쓰고 전자소송이 PDF 로 자동생성. 법원이 준 문서 아님
- ② **첨부서류** = 박씨가 증빙으로 확보한 등기부등본 원본
- 법원이 준 것은 "보정명령등본" — 제출에 포함하지 않음
- 전자소송은 항상 "본문 서면 + 첨부" 세트. 첨부만 단독 제출하는 경로는 없음

## 5. GUI 자동화 메모 (재사용)

- **screen-pilot MCP 연결됨** (09-28). 좌표는 1366×768 스케일, 실제 1920×1080 으로 자동 변환 (×1.4056)
- 마우스가 (0,0) 모서리에 있으면 **pyautogui fail-safe 로 클릭 실패** → Windows python 으로 중앙 이동 후 재시도
- 한글 입력: `ecfs_pyauto.set_clipboard_text()` + Ctrl+V. 빈 칸이면 Ctrl+A 쓰지 않음
- **파일 열기 대화상자**: 파일이름 칸 클릭 → 스크린샷으로 파란 테두리(포커스) 확인 → 전체경로 붙여넣기 → 경로 확인 스크린샷 → 열기. 업로드 원본은 `C:\Temp\ecourt\` (Downloads 회피) — 09-18 219개 휴지통 사고 재발 없음
- 뷰어 스크롤이 페이지 스크롤을 먹음 → 페이지 스크롤은 좌측 여백(x≈200)에서 `pyautogui.scroll`
- 페이지가 스크롤·배너로 밀려 두 번 오클릭(소년보호재판 안내 페이지 · 사건정보 행) — 둘 다 읽기 전용이라 무해. 교훈: 클릭 직전 스크린샷 좌표 사용
- 화면 캡처: PowerShell CopyFromScreen 은 DPI 150% 에서 좌측만 찍힘 → Windows python `SetProcessDpiAwareness(2)` + `pyautogui.screenshot()` 로 1920×1080 전체
- 전자소송 뷰어 "파일저장" = 대화상자 없이 `D:\UserFolders\Downloads` 로 바로 저장 (Chrome 기본 다운로드 폴더가 D: 임)
